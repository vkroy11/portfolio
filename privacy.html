Privacy Policy

claude-gmail is a personal tool built and used only by Vishal Kumar Roy. It lets Claude Code, an AI coding assistant running on Vishal's own computer, read his Gmail and create email drafts in his own account. It is not offered to the public.

Data the app accesses

  • Read access (gmail.readonly): message and thread content, metadata and labels, so the assistant can find and summarize email when asked.
  • Compose access (gmail.compose): creating and updating drafts. The app does not send email on its own; drafts are reviewed and sent by the account owner.

How data is used

Gmail data is used only to carry out the request the account owner makes in a chat session, such as finding a thread or drafting a reply. It is not used for advertising, sold, or used to build profiles.

Storage and sharing

The app runs no servers and keeps no database. OAuth tokens are stored on the owner's computer in the macOS Keychain. Email content passes through the AI assistant service (Anthropic's Claude) to answer the owner's request. It is not shared with anyone else, except where the law requires it.

Google API Services User Data Policy

claude-gmail's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Removing it makes stored tokens stop working.
